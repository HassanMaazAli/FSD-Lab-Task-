# Meridian S1: Smartwatch Configurator

An interactive product configurator built with plain HTML, CSS and JavaScript. No frameworks or dependencies.

## Features

- **Live preview:** switch between Black, Silver and Blue finishes and see the watch update instantly
- **Custom engraving:** type a name (up to 15 characters) with a live character counter
- **3D tilt effect:** the watch follows your mouse
- **Drag and drop cart:** drag the watch into the cart, or use the Add to cart button on touch devices
- **Form validation:** asks for an engraved name before saving
- **Reset:** restores every option to its default
- **Scroll progress bar** and popup notifications for feedback
- **Copy and cut protection** on the product description
- **Responsive:** works on desktop, tablet and mobile
- **Accessible:** visible keyboard focus and reduced-motion support

## Project structure

## Getting started

1. Clone the repository:
```bash
   git clone https://github.com/YOUR-USERNAME/product-configurator.git
```
2. Open `index.html` in your browser.

No build step or installation needed.
